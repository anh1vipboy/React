# Image Files Directory

Place your image files in this directory with the following names:

## Required Images:

1. **image 24.png** - Main logo (displayed in header and footer)
2. **logoHome.png** - Home icon for navigation menu
3. **Mask group.png** - Hero section main image (Prime Minister photo)
4. **icon _clock time.png** - Clock icon for timestamps
5. **Bộ Tài chính bãi bỏ một số thông tư trong lĩnh vực tài sản công.png** - Featured news image
6. **ảnh-01 1.png** - Full width banner image
7. **banner-cttdtpd_2019133928.png** - Partner banner image (used 8 times in grid)

## Image Specifications:

- **Logo (image 24.png)**: Recommended size 100x100px
- **Home Logo (logoHome.png)**: Recommended size 60x60px
- **Hero Image (Mask group.png)**: Recommended size 800x600px
- **Clock Icon**: 16x16px
- **News Image**: 400x300px
- **Full Banner**: 1920x400px or similar wide format
- **Partner Banners**: 300x200px

## Notes:

- All images should be in PNG or JPG format
- Images will be automatically optimized by Next.js Image component
- You can update image paths in the JSON files located in `/data` directory
